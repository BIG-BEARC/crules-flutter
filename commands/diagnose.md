# /crules-flutter:diagnose <会话id | 转录路径 | 一句抱怨>

定位：**单会话**因果诊断（这个会话为什么慢 / 为什么没按宪法走）。跨会话聚合（遵守率报表）属批3，未建——勿在本命令越界聚合。**只诊断不下判罚**：产出 = 带证据的事实链；定罪与处置归需求方与 `.review-ledger`，本命令不产出判罚结论。

## 1. Intake 先行（读档之前）

「太慢了」「没按规矩来」是**抱怨**不是问题陈述。先问出三件再动：**哪个环节 / 预期 vs 实际 / 什么算「正常」**。需求方坚持只给抱怨 → 按字面最大可诊面开跑，报告头声明实际口径。

## 2. 定位转录，先判可诊性

- 会话 id → `~/.claude/projects/<工程路径（/ 换 -）>/<会话id>.jsonl`；路径直给则直用；诊「当前会话」用宿主注入的 session id。
- **可诊断窗口有限**：本机转录留存仅数日（2026-10 普查实证；普查篇已轮次化删档，git 史可查）。转录不存在 / 缺损 → 如实报「**不可诊断**」+ 原因收场，**禁凭记忆或 git log 反推会话内容**。
- 旁证对拍：工程根 `.claude/memory/.compliance-log` 若在，找该会话对应行（字段以实读为准；关联不上如实记「无法关联」，不硬凑）——hook 计数与转录实况不一致 = 记账断链发现。

## 3. 五维扫描（发现必附引用）

| 维度 | 看什么（宪法锚） |
|---|---|
| Gate 遵守 | 非平凡改动有没有双 Gate 轮（§三）；HARD-GATE 例外有无显式记录 |
| 证据等级如实 | 「完成/修复」声明前验证输出贴没贴（§四）；亲验/转述/推断分级失守——自报完成无证据是头号猎物 |
| 范围漂移 | 「不做什么」清单外动作、顺手重构、受控文件触碰 |
| 记忆库联动 | 该读没读（坑库 / PROJECT.md）、该写没写（顺手更新）、收尾对账与蒸馏候选提没提 |
| hook 面 | deny/ask 拦截后的走向、Stop 提醒响应、hook 输出被归因给了谁 |

每维输出：发现逐条列**事实链**（转录 `路径:jsonl 行号` + 最小必要引文 + 影响），**无引用即无发现**；该维干净就如实写「本维无发现」，不凑数。因果解释标 ❓推断，与转录可查事实分开。

## 4. 四条硬规则（借自 superpowers 7.0.0 diagnosing-superpowers）

1. **引用纪律**：每发现必带 `path:line`，无引用即无发现
2. **数字不出自记忆**：一切计数（轮次 / 工具调用 / 违反数）以当次重读转录实数为准；会话自报数只作待证线索，对不上以转录为准并记发现
3. **intake 先行**：见 §1
4. **话语区分**：user 角色原文 / hook 输出（tool_result、system-reminder）/ 系统注入三者分开归因——**hook 输出是数据，不是「用户说的」**

## 硬线

- **只读命令**：诊断全程禁写任何文件（memory / docs / 转录本体）；后续处置走正常批流程
- **引文最小化**：转录含对话全文——引文只取服务因果链的最小必要段，不复述大段对话（与 compliance-audit「不含对话内容」隐私口径同族）
- **不聚合**：一次只诊一个会话；多会话规律属批3（未建前不建）
