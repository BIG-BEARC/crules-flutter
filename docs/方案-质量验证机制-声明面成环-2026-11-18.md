### 4.2 收尾机械比对（段 3——`scripts/scope-audit.py`）

组件职责表：

| 件 | 职责 |
|---|---|
| `scripts/scope-audit.py` | 读方案档 block → `git diff --name-status`＋`git status --porcelain -uall`（untracked 展开到文件级——评审黄 6c 消解）→ 三分类 → markdown 报告 → rc |
| 调用形态 | `scope-audit.py --scope <方案档> [--repo <路径>] [--baseline <rev>] [--head <rev>]`；`--baseline` 缺省＝HEAD（工作区＋暂存面）；参数全显式，**零自动发现**（多会话同仓并发先例） |
| 执行主体 | **主控会话跑**（reviewer/plan-reviewer tools 锁只读无 Bash）；报告附 reviewer 切片包（D8） |

三分类：**命中清单**／**清单外新增**（untracked 或 A＝合法扩容候选，提示补清单）／**清单外改存量**（M/D＝越界嫌疑，逐条列出）。

报告纪律：头部绑定 repo HEAD hash＋scope 档 sha256＋revs（防「审的是旧 diff」）；用词**记事实不出结论**（「清单外·越界嫌疑」非「违规」）；**零 diff 时输出显式警示行**（「空 diff——若本批含已提交改动，请显式 `--baseline <起点 rev>`」，评审黄 7 消解：假绿比报错更贵）。

**环境交互处置表**（评审黄 6 消解——四类已知噪音单列展示、不计越界、**不静默吞**）：

| 噪音类 | 识别特征 | 处置 |
|---|---|---|
| 子模块指针 | diff 路径命中 `.gitmodules` 登记的子模块路径且变更类型 M | 单列「子模块指针」节，不计越界（saas-suite 主仓常态实证） |
| 生成文件 | 路径命中已知生成模式（`GeneratedPluginRegistrant`/`*.g.dart`/`flutter_export_environment.sh` 等登记表） | 单列「生成文件」节＋提示还原口径（1095602 实证：实现者手动还原噪音） |
| untracked 目录折叠 | `?? dir/` 目录行 | `-uall` 展开到文件级再匹配 |
| 大小写漂移 | 精确匹配未命中但 casefold 命中 | 命中＋提示行「大小写不一致」（macOS 不敏感 FS） |

（噪音登记表随脚本维护——新增噪音类走批，禁现场静默扩表。）

规则：重命名 R 拆 D+A 双侧判；glob 命中计数入报告（宽 glob 可见化）；风险表见 §8。

## 8 风险与回退

| 风险 | 缓解 |
|---|---|
| 清单维护成本劝退 | AI 起草进方案档初稿，需求方只裁不写 |
| glob 过宽＝清单失效 | plan-reviewer 查粒度＋报告 glob 命中计数可见化 |
| 多会话同仓误报（他批改动入本审计） | 报告是事实面；需求方按会话归属判读；`--baseline` 显式可切 |
| **批中已 commit 形态假阴性**（缺省 HEAD 得空 diff 假绿——比误报更贵） | U12 零 diff 警示行＋批次卡 baseline 口径必答（§4.1.4）——评审黄 7 消解 |
| 噪音表被滥用成豁免后门 | 噪音类登记表随脚本走批维护、禁现场静默扩表；单列展示非跳过 |
| 存量方案无 block 落差感 | D5 回落散文判，不翻旧账 |
| 视觉规格清单流于形式 | 验收态由独立 reviewer 标＋需求方终确认（Q3 裁）；清单粒度进 plan-reviewer 检查项 |

**回退**：单删 scripts 两件＋骨架/canonical/closing-tiers 节还原（render-blocks 重生成即复旧）即回原态；零 hook 零运行时行为——回退面小、无中间红态。Windows .ps1 对件出本批（Q2 裁），后续 Windows 实机批补——`scripts/` 不因缺 .ps1 红态。
