## 1 三审互纠模式有效——每轮都抓到前轮实质错误

- 外审（我产）13 项发现，被复核证伪 2 处（「抑制」系 3.5 旧版行为、retrofit「边缘化」判断错）+ 勘 6 处
- 复核被复核之复核纠出 **1 处实质错误**（additionalContext「无死循环风险」与官方文档相反——照抄会连环续轮）+ 2 处版本号查无出处
- 模式要点：**每轮独立实证**（真机实验 / 官方文档原句 / API 取数），不采信前轮自述——评审的价值来自「重新验证」而非「复述同意」
- **【待蒸馏】**：三审链（产出→复核→复核之复核，每轮独立实证）可复用为本包重大变更的标准评审流程——是否并入 `进阶/方案评审闭环.md` 待裁决

## 2 环境隔夜会变——「昨天全绿今天红」三连

- bash 5.3.15（brew 00:29 升级）：`set -u` 下 `$var` 紧邻多字节字符吸首字节入变量名 → install.sh 汇总行中止于**文件已写完之后**（最危险形态）；CI bash 5.2 无此行为故远端无感
- brew python3 运行中途消失（前半段命中、后半段 127）
- 教训：**长脚本验证失败先查解释器/环境再查代码**；`$var` 后接中文标点一律 `${var}`（12 处已修，入 test-self 头注）
