- **再评估结论**：F2 的**实际受影响面 = 在 Windows 原生（无 Git Bash）上使用 Claude Code 的开发者**——这是长尾中的长尾。相比之下，F2 的成本是**引入双语言实现 = 新的孪生维护面**（deny-list 是安全关键件，1.0.8 堵绕过 / 1.0.11 扩面都在演进；双份须同步，正是本仓最忌的「孪生漂移」）——**成本高、收益面窄**，与初始排序相悖。
