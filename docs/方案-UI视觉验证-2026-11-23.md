## 1 目标与范围

**要解决**：

1. **图不落验证链**——设计图（TAPD 附件/蓝湖/Figma/存量截图四源）给了，实现完没人对照；UI 验收靠印象（姊妹篇 P6 实证：零 golden、图不落验证链）。
2. **静默改 UI 无提示**——越界面已被 scope-audit 砍住（文件面），但「改了文件却没按图做」的语义面仍无闸。
3. **验收无独立产物**——UI 类任务交付时没有逐项对照记录，FULL/PARTIAL/NONE 验收态（D3 已裁格式）无承载流程。

**不做什么**：不动消费工程任何受控文件（边界令沿承——本仓出**规程**，落目录/截图属消费侧批次工作产物）；不做 golden 像素基线（V8 否决立论）；不做全平台截图脚本族（B 线按摩擦逐平台后续批）；不做 TAPD/蓝湖/Figma 自动拉料（BrowserSkill 自动化留后续——先证明比对值钱）；批 2 断言层不预铺存量页。

**老行为变更清单**：

|---|---|---|
| 1 | 收尾标准档 UI 类任务追加**视觉验收步**（独立 agent 依规程验收，产物进 review 切片包） | closing-tiers 单一源＋双模板生成连带（1.3.11 刚动过——本批在 review 步括号内**追加条件句**，目标文本见 §4.1〔评审黄 5 消解〕） |

## 4 目标方案

### 4.0 倒选说明

brainstorm 会话三轮：纯目录约定流程（A）→ 挑战后升两层形（A+，采纳）→ golden（C，否决立论见 V8）／全平台脚本族（B，降为后续摩擦驱动）。需求方 2026-11-23 挑战「还有更好的方案吗」引出断言层补强——本篇即 A+ 形。

### 4.1 批 1 结构（语义比对层）

**规程件**（canonical/review-core.md 新增条，生成连带两件）：

1. **取料**：批次卡声明「受影响页面清单＋参照物落位」（design/ 路径）；清单粒度＝**页×受影响设备×必拍态**（态沿骨架交互态空/加载/错误——按页面实际涉面裁，不强制全态；评审黄 9 消解）；主控核在场性——缺→NONE＋显式行，停在此。
2. **代拍/收图**：设备连着（安卓系）→主控 adb 拍各受影响页面入 shots/；否则人喂。shots 缺页→该页 PARTIAL＋缺口行。
3. **独立比对**：reviewer **重读**参照图自建对照清单（不信实现者清单——防自标粉饰）；逐页逐项比 shots；争议项（色值/间距精度）→ **主控代调** zai ui_diff_check（reviewer 无 MCP 面——同代拍逻辑；参数与返回**原文**进切片包供 reviewer/需求方直读，≤2 并发禁扇出）；产物＝逐项差异表（参照项｜层 2 判定｜证据＝截图文件名＋区域描述）。
4. **判定**：页级 FULL/PARTIAL/NONE＋总态；**总态聚合临时口径**＝任一页 NONE→总态 NONE＋原因行（与 AC2 一致；其余取最差非 NONE 态）——临时口径，试点回填时终裁定稿〔评审黄 9〕；差异表＋自查记录（V6）进 review 切片包；需求方终确认。
5. **降级路径**：zai 额度尽→纯读图判定＋「降级」标注行；无设备无图→NONE＋原因行——**记事实不出结论，裁决归需求方**（姊妹篇同纪律）。

**挂载**：closing-tiers 标准档 review 步括号内追加条件句（落位＝机械验证步之后、自测之前；评审黄 5 消解给出目标文本）。**目标文本**（追加于 review 步括号内）：

> UI 类任务（批次卡声明；scope-audit 报告含 UI 文件未声明时提示行不硬拦）加跑**视觉验收**——规程＝checklist 视觉验收条（生成自 canonical/review-core.md）：主控代拍截图/代调 zai，独立 reviewer 判定页级 FULL/PARTIAL/NONE＋差异表，产物进 review 切片包

「UI 文件」判定面最低定义（评审绿 15 建议采纳）：**批次卡声明为准**；报告侧路径含 pages/view/widget/screen 层级作提示源——防实施批各自发明。

**切片包契约不动**（评审黄 13b）：视觉验收产物随报告附包系主控实践扩展，非 review 切片包契约变更（沿姊妹篇显式声明先例）。

### 4.2 批 2 结构（机械断言层，排队·批 1 试点效果后启）

- 视觉规格清单可测项（尺寸/字号/色值/间距/可见性五类首批）→ 实现时写 widget test 断言；跑测试即闭环，层 2 只管断言外项。
- 新 UI 页起用；复刻存量页缓铺（ retrofit 成本高，首碰批次再补）。
- 与 analyze-baseline 的关系：断言测试属消费工程测试面（flutter test），不进本仓脚本——本仓只出规程与骨架扩写。

### 6.3 机制性指标
