# 返工账：验收前移 + 漏项归因

> 本文件为 parity-rewrite skill 机制条文，SKILL.md 执行到〔Phase 2 定稿、Phase 4〕时 Read 本文件。

返工是最大的效率黑洞，且其上游正是弹窗漏读与重造——漏枚举与重造都在后期变返工。

- **Human Gate 前移**：Phase 2 清单定稿须经需求方确认「这张表完整」才开工——"完整"以 [closure.md](closure.md)「完整性单一判据」为准（含作用域登记与前批销账核对）——枚举漏网的账从"上线后"前移到"开工前"
- **全绿硬闸**：每批次测试矩阵全绿才进下一批——硬闸，不是收尾动作
- **返工登记**：验收期任何漏项回填清单并记根因（枚举漏 / 隐含假设补 / 弹窗树未进 / 重造 / 越界）——skill 自身效率首有读数，归因数据供下批复用与回灌
