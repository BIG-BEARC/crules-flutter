## 4 目标方案

### 4.0 第 0 步：迁移性微测（D2，裁决后第一个动作）

**大白话**：对方的规律是在英文过程手册上验证的，咱们的宪法是中文领域规则书——先花一次实验确认规律搬得动，再决定把它写成纪律还是只记在设计启发账上。

- 对象（Q2 已裁默认案）：宪法 §一「必须简洁直接」（典型 shaping 禁止式候选——「不写废话/不重复/不过度铺垫」正是对方实测会反噬的写法）。
- 设计：原文 vs 配方式重写 vs 无指导空白对照，三臂各 5 rep（单次新鲜上下文 subagent，system prompt 载宪法真实上下文），产出物按对方判据人工逐条读 + 记方差。
- **判据预注册（2026-10-16 跑前写死，评审 Q2 加强项——防判读移动球门）**：每份产出按四指标人工逐条读——① 结论先行（第一行是否直接给出「做了什么+结果」，是/否）② 废话句数（铺垫句 / 复述任务句 / 重复解释句 / 空话收尾句，逐句计数）③ 正文字符数 ④ 形态注记。**分流判据**：任一指导臂相对无指导对照「废话句中位数下降且结论先行数不降」且方向与对方结论一致（配方 ≥ 禁止式）→ 迁移成立；三臂指标重叠无序 → 不成立；仅配方臂有效 → 部分成立（D1 全量、纪律侧重配方侧）。局限如实记：n=5 小样本、单任务、判读者非盲。
- 执行环境注（已核 2026-10-16）：通用 subagent、本仓根无 CLAUDE.md、本机无用户级 CLAUDE.md——宪法条文全部经 prompt 显式注入；宿主注入的 using-superpowers 常驻文本三臂同受，内部效度不受损。
- 产出：`docs/验证-2026-10-16-条文形态迁移微测.md`（原始输出留档，遵循自报不可靠纪律——记录≠结论，结论随数据）。
- 分流：迁移成立/部分成立 → D1 全量生效；不成立 → D1 降级为「记录在案的设计启发」，本批缩为 D4–D6。
- **结果（2026-10-16 已跑毕）：迁移成立 → D1 全量生效**。全文见 [验证-2026-10-16-条文形态迁移微测.md](验证-2026-10-16-条文形态迁移微测.md)。要数：结论先行 A 0/5 · B 2/5 · C 5/5；废话/邀约句中位 A 1 · B 0 · C 0；字符 median A 285 / B 233 / C 252；「大白话括注」条文特有行为仅现 B 臂 3/5（条文被逐条读取的硬证据）；未观察到禁止式反噬（B 无一份劣于 A）。两条如实注记：① C 臂 5/5 编造文件路径满足配方槽位 → 「槽位须有真实信息源」进 D1 条文；② B 臂注入含正例半句，反噬结论仅对现行 §一 混合形态成立。

### 4.1 改条文纪律（一）：失败类型→条文形态（D1 前半）

README 维护节新增条目「改条文纪律」，内联对方四行配对表（翻译 + 本仓例）：

| 基线失败类型 | 该用的条文形态 | 本仓例 |
|---|---|---|
| 压力下违反规则（知道但做不到） | 禁止式 + 合理化表 + 红旗 | §一 红线（现行正确） |
| 守规但产出形状错（膨胀/埋结论/复述） | **正例配方**（写明产出是什么、分几段、什么顺序）——禁止式实测反噬 | §五 完成定义（现行正确） |
| 漏必件 | 模板开必填槽位，不写旁注散文 | 裁决区「无待裁决项」空态契约（现行正确） |
| 行为该随条件变 | 绑可观察判据的条件式 | 收尾三档判定行（现行正确） |

附带两律同条内联：① 赢家配方禁加「除非…」nuance 从句（实测劣化）；② 豁免从句圈不住范围，须豁免就重构规则使其够不着。**显式化价值**：现状是凭直觉做对了（§四/§五/三档都是对的形态）——直觉不传代，显式化后新条文有前置检查。位置：README「每次 minor 例行」组之后、「原则与观测项」组之前；消费面零新增。

### 4.2 改条文纪律（二）：微测义务（D1 后半）

- **触发**（Q3 裁）：红线级条文的**新增 / 判据改写 / 措辞实质变更**；格式修正、生成块重渲、错别字不触发。
- **动作**：改动前跑对照微测（同 §4.0 设计，规模可缩至 2 臂×5 rep），记录落 `docs/验证-*` 篇。
- **流程位（评审 R5）**：形态判定与微测在 **canonical 源文**上进行，通过后方进生成闸重渲与双模板同步——防微测测的是渲染产物致结论不可复用。
- **止损线**（治理从简·新闸带到期动作）：连续 3 次微测结论均为「两形态无差异」→ 义务降级为可选（记 Gate 例外通道），防仪式化空转。
- **成本预算**：单次 ≈ 10–15 个 subagent 调用，单维护者可负担；极简批（1.1.x 内 non-constitutional 改动）永不触发。

### 4.3 合理化对照表（D3，挂起）

升级对象 = compliance-log 聚合出的**实测违反最多**的红线（预计候选：自报完成 / 顺手重构 / 范围漂移），形态 = Excuse/Reality 二列表 + 红旗清单，落 canonical 红线块旁（生成面）。**挂起条件**：compliance N≥30 或批3 聚合产出首批报表，二者先到。常驻成本届时逐 token 记账（预算 ≈ 200–400 tok，10.2K/15K 线内可容）。

### 4.4 `/crules-flutter:diagnose`（D4，阶段 3）

- 落位：`commands/diagnose.md` 新命令（+必要时 references 单文件）。输入 = 会话 id / transcript 路径 / 一句抱怨；输出 = 按维度分节的诊断报告（每发现必带 `path:line`，无引用即无发现）。
- 与批3 边界（Q4 裁）：本命令管**单会话**因果（这个会话为什么慢/为什么没按宪法走）；批3 管**跨会话聚合**（遵守率报表）。互补不重叠，读侧同源（`.compliance-log` + transcript）。
- 借对方四条硬规则：引用纪律 / 数字不出自记忆 / intake 先行（「太慢了」是抱怨不是问题陈述，先问出问题陈述再动）/ user 话语与 hook 输出、系统提醒严格区分。
- **只诊断不下判罚**：与普查「记事实不出结论」同族——定罪归人与 ledger，命令只产出带证据的事实链。
- 不借的部分：bundle 打包/scrub 流程、GitHub issue 流（私域无此面）；七维全跑（本仓维度按宪法域裁为 5 个：Gate 遵守 / 证据等级如实 / 范围漂移 / 记忆库联动 / hook 面）。
- **落位注（评审 R11/R12）**：普查 :11-12 实证本机转录留存仅数日——命令文档须写明可诊断窗口限制，超窗会话如实报「不可诊断」；help 场景表 parity 行为路由表性质，description 改后核一句相容即可。
