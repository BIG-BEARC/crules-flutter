## 2 机制设计原则（每缺陷的「土壤」与消灭方式）

| 缺陷 | 发生的设计土壤 | 机制级修法（对比：补丁修法） |
|---|---|---|
| P0-1 | 同文件两签名两套边界纪律：`GIT_SIG` 用 `\b` 词边界（天然免疫路径前缀），`RM_SIG` 自造边界类 `[\s(...)]`（枚举必漏） | **统一边界纪律**：命令签名一律 `\b` 词边界，写进头注设计纪律＋夹具形态矩阵锁未来签名。补丁版＝边界类里补 `/`（下一个漏掉的字符还在路上） |
| P0-2 | 旗标解析域不一致：stash/checkout 分支已用 `seg[m.end(1):]`（子命令后），push/reset/clean/branch 用 `seg.split()`（全段）——同族四种写法 | **统一解析域纪律**：族内全部分支改用既有 `m.end(1)` 惯例（仓库自己已发明了正确答案，只是没铺开）。补丁版＝push 分支特判文件名 |
| P0-3 | 闸把「能力缺失」（无 tag）与「能力不可用」（非 git 树）混为一谈：rc≠0 才 SKIP，rc=0 空 tag 集静默盲跑 | **闸自盲检测**：git 仓＋零 tag＋有段头 = 环境失明，按红拒绝盲跑；CI 侧 fetch-depth: 0 双保险。补丁版＝ci.yml 加一行 fetch-depth（本地浅克隆照样盲） |
| P1-6 | 承诺落在设计文档、实现没人验 | **把承诺变成有夹具的代码**：state 键＋Stop 闸＋测试三件套；test-self 锚串钉住「init 写、hook 验」两端不再脱钩 |
| 同文 ×7 / 双载体漂移 | 逐字同文无 gen 标记＝canonical 机制没覆盖到 | **收编既有 canonical 机制**（render-blocks 已成熟，1.0.35 agents 先例），扩登记表而非造新机制 |
| P1-5 | 机制只有「入」没有「出」 | 止损裁决单（呈裁件）＋ CHANGELOG 前向体例（增量止血，存量零迁移） |

## 2.5 Review Focus（实现与评审双用·五类最可能反噬面）

1. **词边界新命中面**：`\brm\b` 使 `=`/`,`/`>` 后的 rm 形态进判定（`x=$(rm -rf ~)`）——期望 deny（rm 分支 has_r+has_f+白名单判据不因边界换而变）；A1 夹具锁定、A2 Step 6 回归。
2. **旗标在子命令前的全局形**：`git -C /x push --force`、`git --no-pager push origin +m`——期望均 deny（危险旗标/refspec 恒在子命令后，args 域不丢）；A1 夹具锁定。
3. **ps1 IgnoreCase 叠 `\b`**：`/BIN/RM -RF`——ps 侧拦（D-b IgnoreCase 声明域）、py 侧放行（bash 语义大小写敏感＝正确行为），双源差异属已声明族；A1 lang:ps 例锁定。
4. **state 半行/损坏容错**：`.crules-state` 截断行或 CRLF——对拍闸静默跳过（except 兜底），Stop hook 不崩；C1 Step 1 加 ③′ 分支。
5. **非典型环境退化**：CHANGELOG 缺失/非 git SRC——lag 出 `?`、原三分支行为不回归；C4 Step 2 实跑兼验。

# crules-flutter 安装痕迹巡检——多工程视图（2026-10-19 评审 P1-8：掉队距离=CHANGELOG 段序投影，零台账文件）

[ $# -ge 1 ] || { echo "用法: bash scripts/check-imports.sh <消费项目根> [更多根…]"; exit 2; }
SRC_VER=$(grep -m1 -oE '"version":[[:space:]]*"[0-9]+\.[0-9]+\.[0-9]+"' "$SRC/.claude-plugin/plugin.json" | grep -oE '[0-9]+\.[0-9]+\.[0-9]+')

# 递减，故差取 index(戳)−index(源)：戳旧于源 → 正数＝掉队 N 版；负数＝源更旧（plugin update 回滚态，1.0.34
# 裁勿刷）；任一不在序或 CHANGELOG 不可读 → "?"（前置可读守卫——文件缺失时 awk 报错且输出空，[ "" -gt 0 ]
# 会静默落错分支）。段头实为「## 1.1.9 · 标题」形——前缀匹配禁 $ 尾锚（评审 M1；test-self:761 同款先例）。
lag() { [ -r "$SRC/CHANGELOG.md" ] || { echo "?"; return; }
  awk -v a="$1" -v b="$2" '
  match($0, /^## [0-9]+\.[0-9]+\.[0-9]+/) { v = substr($0, 4, RLENGTH - 3); n++; if (v == a) ia = n; if (v == b) ib = n }
  END { print (ia > 0 && ib > 0) ? ia - ib : "?" }' "$SRC/CHANGELOG.md"; }

  STAMP=""; STAMP_FORM=""
  for cm in "$TARGET/.claude/CLAUDE.md" "$TARGET/CLAUDE.md"; do

        *) STAMP_FORM="根 CLAUDE.md（丁-tracked 存量——迁移=阶段 4 授权批）" ;;
      esac
      break
    fi
  done
  if [ -z "$STAMP" ]; then
    echo "$(basename "$TARGET") | 🟢 未检出 crules-flutter 戳（早期安装或非本包装载——新装走 /crules-flutter:init）"

    if [ "$LAG" = "?" ]; then
      echo "$(basename "$TARGET") | 🟡 段序定位失败：v$STAMP ↔ 源 v$SRC_VER（戳或源不在 CHANGELOG 段序——按两段人工对照）"

    else
      echo "$(basename "$TARGET") | 🟡 源更旧：项目 ${STAMP_FORM} v${STAMP}，源现为 v$SRC_VER——勿刷（plugin update 回滚态由需求方裁）"
    fi
  fi

  # 不做目标全量比对（项目自定义内容会全成噪音）；KEEP 语义下机制演进靠人合并
  if [ -d "$TARGET/.claude/memory" ]; then
    for f in "$SRC"/memory/*.md; do b=$(basename "$f")
      [ -f "$TARGET/.claude/memory/$b" ] || echo "🟡 memory 新模板未落位：${b}（KEEP 语义不自动补——人工对照源模板合并）"
    done
    if [ -n "$STAMP" ] && [ "$STAMP" != "$SRC_VER" ]; then

      if ! git -C "$SRC" rev-parse --is-inside-work-tree >/dev/null 2>&1; then

      elif ! git -C "$SRC" rev-parse -q --verify "refs/tags/v$STAMP" >/dev/null; then
        echo "🟡 源仓无 tag v${STAMP}（1.0.2 前发版未打 tag，历史不回补）——memory 模板演进比对不可用，改按 CHANGELOG v${STAMP}→v${SRC_VER} 段人工对照"

        done
      fi
    fi
  fi
done
exit 0
