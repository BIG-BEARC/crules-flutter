# 方案：屏幕适配三选一 + 字体策略公共节 + 文件头跟随（模板演进）

> **2026-09-08 评审终裁**：① 版本 0.5.3 → **0.6.0 minor**（本文「0.5.3」字样按此读作）；② 阻1——适配三选一/字体策略**仅落 app 模板**（`###` 子节入 §七/8.1，不新增 `##` 节防孪生守护炸），plugin §八 +1 行指针；文件头跟随双模板都落；③ 断点统一三档（<600/840/≥840），桌面注可扩 large/extra-large。

> 状态：讨论稿（待评审）· 日期：2026-09-08 · 关联需求：复审 0.5.2 发现的 🔴 checklist 与模板适配口径矛盾 + saas-cashier 字体坑实证 + S13 文件头渗漏裁决 · 面向对象：crules-flutter 维护者

## 1 目标与范围

**要解决什么**：① 适配方案是项目语境依赖的决策（按稿还原 vs 多端），模板硬编单一答案会错一半——升级为 §七显式三选一；② 字体坑（Android OEM 字重裁剪 / Windows 缺中文字体）是跨项目实证坑，其策略不属于任何一档适配方案，作为**公共必选节**落模板；③ checklist 47/80 行与模板预设口径矛盾（复审批 🔴），随本批对齐；④ **S13 并入**：文件头 @Author 五件套系 saas_pos 公司制度渗漏（fork-coverage §三批 3a 只把公司名换占位、未改「默认要求」本身）——改为「默认跟随项目现状 + §十二附录覆写」。

**不做什么**：不动 skill references 的布局内容（C1/C2 坑卡属吸收批）；不改 init 落位物形态（适配选择并入 §七既有选定环节，不新增必填处）；S14（IoT 抽层）另行落稿，S15 已随 0.5.0 瘦身消化。

## 2 核心决策

1. **§七新增「屏幕适配方案【复制后三选一】」**：A1 弹性优先+断点（默认推荐）／A2 设计稿缩放（按稿还原型）／A3 自定义——交互与既有序目「选定删其余」一致。
2. **适配优先级口径（A1 档内）**：弹性组件（Expanded/Flexible/Wrap）→ LayoutBuilder 断点（Compact<600 / Medium<840 / Expanded≥840 三档语义化，即 window size class 思想）→ 尺寸令牌（ThemeExtension 离散档位）。**禁连续缩放系数**（与系统字体缩放冲突、多端破版）。
3. **A2 档如实标注风险**：flutter_screenutil 5.9.3（2024-05 起 ~28 个月无稳定版、v6 停留 alpha）；`.sp` 与系统 textScale 打架需显式处理；平板/桌面不适用。仅限存量沿用与按稿像素还原型单端项目。
4. **新增「字体策略（公共·三档皆必选）」节**，四要素：
   - **关键字体打包进 app**：不信任设备系统字体回退（Android OEM ROM 裁剪 Roboto/中文字重——flutter#154166，3.22.x 起；Windows 默认中文字体不可用）——Android 打包 Roboto 全字重，桌面打包指定中文字体（实证：saas-cashier `bbf976e42` / `0508ac9b5`）
   - **统一注入点**：平台条件 fontFamily 走统一 TextStyle 工厂/getter（如 AppTextStyles），**禁内联 TextStyle**——内联即绕过注入（实证复发 4 笔：`656558508` 等）
   - **fontFamilyFallback** 显式声明兜底链
   - **特殊链路兜底**：打印等设备无对应字形的场景，文字渲染为图（实证：`aaa9995fd`）
5. **checklist 对齐（非写死 A1）**：47 行改「按项目 §七 所选适配方案对号审查」；80 行「暗黑 / `screenutil` 适配」改「暗黑 / 断点（或项目所选方案）适配」；Flutter 专项新增「新增 TextStyle 走统一注入点（平台字体一致性），无内联绕过」与「打包字体覆盖目标机型（OEM/桌面），fontFamilyFallback 已声明」两条。
6. **不做成运行时 AskUserQuestion**：接入期一次性决策落盘 §七，每会话可见——运行时问 = 每会话重决策，倒退。
7. **S13 文件头改「默认跟随项目现状」**：app/CLAUDE.md:228 与 plugin/CLAUDE.md:254 的 @Author 五件套格式从模板正文撤下，改为：默认规则 = 新建文件作者头**沿用项目主流惯例**（存量普遍带头→循既有格式，但**不含 @Email**——作者权威在 git，头注不双写邮箱；存量普遍无头→不加）；项目可 §十二附录显式覆写「强制开/强制关」；惯例不一致（半有半无）时问一次、答复落附录。零配置时 saas 型项目（存量带头）保持风格一致，新/fork 团队（无头）默认干净——双向都不渗漏。

## 3 目标方案（落点与原文）

### app/CLAUDE.md / plugin/CLAUDE.md §七内新增（预设三选一之后）

```markdown
### 屏幕适配方案【复制后三选一，选定后删其余】

**A1 弹性优先 + 断点（默认推荐·多端 / 长期项目）**
弹性组件（Expanded/Flexible/Wrap）优先 → LayoutBuilder 断点（Compact<600 /
Medium<840/Expanded≥840 三档语义化）→ 字号/间距走 ThemeExtension 离散档位。
禁连续缩放系数（与系统字体缩放冲突、多端破版）。

**A2 设计稿缩放（按稿像素还原·单端项目）**
flutter_screenutil（.w/.h 按稿缩放）。注：5.9.3 后 ~28 个月无稳定版（维护缓慢）；
.sp 与系统字体缩放需显式协调；平板/桌面不适用。仅限存量沿用与像素还原型单端新项目。

**A3 自定义**（在此描述）

### 字体策略（公共·任一适配档皆必选）

- **关键字体打包进 app**，不依赖系统回退：Android 机型 OEM ROM 可能裁剪 Roboto/
  中文字重（字重只剩两档）；Windows 可能缺可用中文字体——按目标平台打包（如 Roboto
  全字重 + 桌面中文字体），pubspec 显式声明 family 与字重映射
- **统一注入点**：平台条件 fontFamily 走统一 TextStyle 工厂/getter；**禁内联
  TextStyle**（内联即绕过注入，桌面端/OEM 机型即现字体缺陷）
- fontFamilyFallback 显式声明兜底链
- 打印等设备无法渲染的字形（维语/阿拉伯语等）：文字渲染为图的兜底链路
```
